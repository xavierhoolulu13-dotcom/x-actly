# x actly

**See them coming back.** The retina of the X series — a lightweight retention tracker. Monthly customers, who's active, who's cooling, who needs a nudge.

## Run it

No install or build step. Open `index.html` in a browser. Data stays in the browser (localStorage).

## What it does

- Monthly recurring revenue at a glance
- Auto status: Active (<30d) → Cooling (30–60d) → Cold (60d+)
- Nudge queue: quietest customers first, one-tap "log visit"
- Add / remove customers, search

Part of the X series: x-it works → x-ist tracks → x-actly retains → x-edust automates.
